# Mon assistant

Assistant vocal personnel : un orbe plein écran, des bulles d'images, la voix, des minuteurs, des notes et des tâches. Tout tient dans un seul fichier, `index.html`.

## Publier sur GitHub Pages

1. Crée un dépôt GitHub et envoie `index.html` à la racine.
2. Dans le dépôt : Settings, Pages, branche `main`, dossier `/ (root)`, Save.
3. Ouvre l'adresse `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Brancher le cerveau

Au premier lancement, les réglages s'ouvrent. Colle ta clé **Groq** (gratuite, console.groq.com) dans Options, puis Enregistrer. La recherche web passe par le modèle `groq/compound`.

- La clé reste dans le navigateur de l'appareil. Ne la mets jamais dans le code ni dans le dépôt.
- Chaque personne qui ouvre la page doit utiliser sa propre clé : sinon ne partage pas l'adresse.
- - Les photos viennent de Wikipédia et les courtes vidéos de Wikimedia Commons, chargées en direct à l'ouverture de la page (aucune clé, rien à héberger). Quand aucun média ne correspond, une scène animée prend le relais.
- Ces médias ne s'affichent pas dans l'aperçu de claude.ai, seulement sur ta page GitHub.

## Photos et vidéos de meilleure qualité (facultatif)

Dans les réglages, onglet Options, tu peux ajouter :

- une clé **Pexels** (gratuite, pexels.com/api) : photos et vidéos ;
- une clé **Unsplash** (gratuite, unsplash.com/developers) : photos.

Sans ces clés, la page utilise Wikipédia et Wikimedia Commons. Les clés restent dans le navigateur, jamais dans le dépôt.
